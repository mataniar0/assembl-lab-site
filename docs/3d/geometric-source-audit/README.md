## מה בדיוק דרוש כדי להשלים

**המסלול הקצר ביותר:** קובץ ההרכבה המקורי של Geometric — STEP עם כל הגופים או פרויקט CAD מקורי כולל חלקים מקושרים — עם יחידות, זיהוי גרסה ואישור שהוא מתאר את השלדה המצולמת. ממנו ניתן להפיק חלקים, מידות ומיקומים בלי לנחש.

אם קיים רק תכנון דו־ממדי, דרושים:

1. קובצי DXF/SVG בקנה מידה 1:1 ששימשו לחיתוך: כל סוגי הדפנות/הרגליים, קורות הפנים והפלטה. כולל החורים, השיניים והחריצים המקוריים, לא איור דומה.

## הצעד הבא לאחר קבלת מקור

לקבע מקור ו־SHA256 → לאמת יחידות, גרסה ו־BOM → לבנות גופים מפרופילי המקור בעוביים המוסמכים → להציב לפי מערכת הצירים המקורית → לבדוק מעטפות, גובה, חיבורים, נפחי חפיפה ומסלולי הכנסה → לתקן רק כשלים שמקורם במימוש בלי לשנות תכנון מאושר → לייצא GLB ביחידות מטרים ובצירים מתועדים → לאמת glTF ולהפיק קדמי/צד/תחתון → QA עצמאי ו־PR. אין להשתמש באיור הנוכחי כתחליף למקור.

הקלט החסר נשאל גם בשיחה במהלך העבודה, בלי לעצור את מחקר המקורות והבדיקות הניתנות לביצוע.
