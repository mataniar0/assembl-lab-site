## הקפאת V1
- 64 נכסים מגרסת המקור הועתקו (כאובייקטי Git זהים או קובץ שירות מותאם) ל־`marketing/v1/`: הדמיית חלל ריאליסטית, CSS/JS, Geometric 15-part frame GLB, שולחן הקפה האישי 32-part GLB לאחר אישור, ספריית model-viewer, תמונות ואייקונים.
- כל קובץ נעול באמצעות SHA של Git blob ב־`marketing/v1/file-manifest.json`. בדיקת Node מתמשכת בודקת כל נכס בנפרד כדי למנוע שינוי בשוגג גם לאחר פיתוחים עתידיים.
- `marketing/v1/app/sw.js` נבדל ב־Cache Storage namespace: `assemble-lab-marketing-v1-*`, ואינו מוחק קבצי `assemble-lab-android-*` של הפיתוח. מסלול ה־Service Worker של כל גרסה מוגבל לתיקיית האפליקציה שלה.
- עמודי הפנייה והקטלוג הלא־כלולים ב־V1 מופיעים כדפי הדגמה לא־פעילים, ללא יכולת לשלוח פנייה אמיתית.
- קוד `main/app/` מתעדכן בנפרד, והסקריפטים שלו משתמשים במטמון בשם `assemble-lab-android-v0.14.4-mode-selection`.

## מה מוצג ומה לא
- הגרסה השיווקית מציגה את Geometric במסך הכניסה, שולחן קפה עם רקע ריאליסטי ותצוגה סכמטית משתנה, ו־GLB קבוע של שולחן הקפה לאחר אישור.
- בחירת מידות/בסיס **אינה** משנה את מודל ה־GLB המקורי; אין פרשנות של התאמה הנדסית או אישור לייצור.
- לא נוצרת הדמיה באמצעות ספק AI ולא נשלחים נתוני הלקוח לענן.
- שתי הכתובות ציבוריות מבחינת גישה; מסך הבחירה אינו אימות או בקרת הרשאות.
