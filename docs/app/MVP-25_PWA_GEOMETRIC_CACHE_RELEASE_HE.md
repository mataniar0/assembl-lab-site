# APP MVP-25 — תיקון ערבוב דגמי 3D במעבר גרסת PWA

**עדיפות:** P1 · **מבצע אפשרי:** ChatGPT / Codex · **מבצע מומלץ ובפועל:** ChatGPT.

## ממצא
בצילום מסך מהאפליקציה לאחר MVP-24 הופיע טקסט **Geometric** ומצב **"מודל תכנון 3D"**, אבל הוויזואל היה שולחן הקפה האישי העגול. קוד המקור ב-main כבר מצביע בכניסה על Geometric V1.1 (שלדה ללא פלטה); לפיכך יש פער בין מסמך HTML מעודכן לבין הנכסים שהדפדפן טוען.

## הסיבה ומנגנון המניעה
הניווט ב-`app/sw.js` הוא **network-first**, אבל בקשות JavaScript/CSS נשמרות במטמון **cache-first**. ה-Service Worker הישן יכול עדיין לשלוט בלשונית בעת התקנת שחרור חדש: מתקבל HTML עם כותרת Geometric ובמקביל `personal-coffee-hero.mjs` מהגרסה הישנה שבונה שולחן עגול. בדיקות MVP-24 הרגילות חסמו Service Worker בבדיקות צילום/3D עם חיבור אינטרנט ולא כיסו מצב של ערבוב גרסאות.

התיקון: קובצי הכניסה (JS/CSS) נטענים באמצעות כתובות עם `?v=mvp25-20261118`, המופיעות **בדיוק באותה גרסה** גם ב-HTML וגם ב-`SHELL` של Service Worker החדש. בקשה מהמסמך העדכני לא תואמת פריט מטמון ישן בכתובת הלא־ממוספרת, ותוריד קובץ JS נכון. הגרסה של תלות `photo-grounded-coffee-glb.mjs` נעולה אף היא במסלול המודל המוחזר. מטמון PWA הועלה ל-`v0.14.1`.

## תחומי ההפרדה המחייבים
- כניסה — תמונת Geometric הקיימת באתר; GLB `geometric-v11-design-only.glb`, **מסגרת בת 15 חלקים ללא פלטה**, ללא אישור ייצור.
- אחרי אישור פרטי הפיילוט — `personal-design-preview.glb` המקורי בן 32 החלקים של שולחן הקפה האישי. אין התאמה פרמטרית לפרטים בטופס השידה הישן.
- לא מחליפים קובצי GLB/תמונות מקור בקטלוג; אין קריאות API חיצוניות או נתוני לקוחות במטמון.

## שערי QA
1. בדיקות Node: תצוגת Geometric, הפרדת דגמים, ומסלולים ממוספרים זהים ב-HTML ובמטמון, ללא גרסאות לא־ממוספרות בכניסה.
2. בדיקת Chromium עם **מטמון PWA ישן מדומה** שמכיל JS/CSS לא־ממוספרים של הגרסה הקודמת: לאחר טעינת HTML חדש יופיע Geometric ותצוגת 3D של שלדה בלבד, ולא שולחן הקפה.
3. בדיקת Chromium רגילה במסכים 390/1440, HE/EN, מעבר תמונה↔3D, מקורות GLB, Offline, אין WebGL.
4. בדיקה ש־Personal Coffee Table חוזר רק לאחר אישור, כולל גרסאות ובדיקות בטיחות קיימות.
5. בדיקות אתר 3D ללא רגרסיות. **מיזוג ל-main רק כאשר הבדיקות המלאות ירוקות.**

## QA / מעקב
קישורים לריצות GitHub Actions ולמחזורי תיקון נרשמים ב-PR. האבחנה של ערבוב הגרסאות נתמכת בקוד ה-Service Worker ובצילום המשתמש; לא נבדק מטמון הדפדפן האישי שלו ישירות.
