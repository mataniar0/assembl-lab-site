אלה מחירי פלט תמונה בתמחור סטנדרטי בלבד, **לא עלות כוללת של בקשה**. יש לכלול גם קלט תמונה/טקסט, צריכה נוספת, שיעורי מטבע ומסים ככל שרלוונטי. ספק יכול לשנות את המחירים והזמינות.

## חוזה API עתידי
- לפי התיעוד, עריכת תמונה נתמכת ב־Gemini Interactions API, endpoint מסוג POST /v1beta/interactions, עם קלט טקסט ותמונה ב־base64 בצד שרת.
- מודול MVP-10-A לא מכיל endpoint, SDK, מפתח או מנגנון שליחה. יש להוסיף אותם אך ורק במתאם שרת מאובטח חדש **אחרי אישור נפרד**.
- ניתן לבחון קודם gemini-3.1-flash-lite-image כחלופה חסכונית במחיר קלט, אך אין להניח איכות מספקת ללא הערכה של תמונה בפועל.

## המלצת התהליך
1. להישאר כרגע ב־DRY RUN ללא חיוב.
2. לפני ניסיון חי יחיד לאמת תמחור ו־API מחדש, להפעיל מגבלת קריאות/תקציב ברמת שרת ולתעד פרטיות ואחסון.
3. לבקש אישור מפורש מראש למודל, למספר קריאות ולסכום מרבי קשיח. אין לבצע בקשה במקרה של חריגה או אי־ידיעת המחיר.
4. לבצע תחילה ניסיון על PNG סינתטי SC-01 בלבד. אין תמונות לקוחות.
5. לאחר יצירה בפועל, לבדוק את איכות הפלט עם קריטריוני G4 והערכה אנושית.

**מסקנה:** Gemini API ליצירת תמונה אינו במסלול חינמי לפי דפי התמחור שנבדקו. לכן MVP-10-B נשאר חסום עד להרשאה נפרדת ולתקציב מוגדר.
