# ASSEMBL LAB — APP MVP-09-B / בדיקות ממשק וסקירה חזותית

**תאריך:** 2026-11-15
**Issue:** #63
**PR:** #64 (Draft)
**ענף:** `feature/app-mvp-09-synthetic-room-review`
**היקף:** מסך הדמיה סכמטית מקומי בלבד, ללא תמונת בית אמיתית, ספק AI או Supabase.

## מה השתנה בשלב B

1. מעבר בין תצוגת לפני, אחרי וגבול השוואה נגרר (wipe) ללא תמונות חיצוניות.
2. שמירת גרסה מועדפת ושחזורה בזיכרון הדף בלבד; איפוס מוחק אותה.
3. חישוב `fittedPlacement` להשארת השידה בתוך תחום ההצגה ברוחבי מסך קטנים; אם המיקום תוקן חזותית, מוצגת הודעה מפורשת.
4. הצגת מידות דוגמה `500×550×350 mm`, סוג חומר, עובי `6 mm`, מגירות, גוון, קנה מידה ומיקום. אלו מידות המחשה ולא מדידות אמיתיות או אישור בטיחות.
5. המרת נתונים מקומית `designIntentFor` אל חוזה `ASSEMBL-LAB.DESIGN-INTENT.0.1` עם רשימת שדות מותרת, ללא תמונות, הערות חופשיות או נתוני לקוח.
6. בדיקות Node יחידה: **16 תרחישים**. בדיקות Chromium: **4 רוחבי מסך (320, 390, 768, 1440 פיקסלים)**, בדיקות תוכן, מקלדת RTL, כפתורי העדפה, שפה והיעדר שימוש ברשת.
7. צילומי QA סינתטיים עבור `390` ו־`1440` במצבי 'אחרי' ו'השוואה'. מיוצרים כארטיפקט GitHub Actions לצורך סקירה, לא מועלים אוטומטית לאתר הציבורי.

## שערי איכות

- **G0 — בטיחות/תחום:** CSP `connect-src 'none'`; אין העלאת תמונה/טקסט, בקשות רשת חיצוניות, API בתשלום או מפתחות.
- **G1 — התאמה לנתונים:** שדות `Design Intent` מוגבלים ומסומנים סינתטיים, שינוי מיקום וסולם מיוצג ב־CSS; השידה נשארת בקנבס במובייל.
- **G2 — UX ונגישות:** HE/EN, RTL/LTR, מחוונים נגישים למקלדת, `aria-pressed`, סטטוס נגיש, `prefers-reduced-motion`.
- **G3 — בדיקות:** Node ו־Chromium כולל צילום לפני/אחרי, 4 רוחבים, בדיקת אי־העברת נתונים ובקרות מועדפים. אין בדיקות משתמשים אמיתיים.
- **G4 — בקרת מוצר:** סקירה עצמאית מצילומי מסך של Android-width + desktop. מיזוג ופרסום מחייבים אישור מפורש.

## מחזורי תיקון

1. **מחזור בדיקות #1** — התאמת ציפיית ArrowLeft להתנהגות `input[type=range]` ב־RTL; אין שינוי במוצר.
2. **מחזור עיצוב #1** — צילום מובייל הצביע על גובה חריג לכפתורי ״גרסה מועדפת״ בגלל `flex-basis` בכיוון עמודה. תוקן ב־CSS ונוספה בדיקת גובה (44–70 פיקסלים).
3. בדיקות חוזרות: נדרשת תוצאה סופית של CI ומעבר חזותי על צילומי המסך לאחר התיקון.
