## רגרסיות ובטיחות

נבדקו שדות חובה ופרטי קשר שגויים, הודעות ותיקוף בהחלפת שפה, הצלחה מדומה, HTTP 422/500, כשל רשת, timeout, JSON פגום והיעדר אישור בתשובה, מניעת שליחה כפולה והחלפת שפה בזמן שליחה ממתינה ולאחר הצלחה/שגיאה. בדיקות הנתונים משתמשות בערכי fixture בלבד; גופי פניות אינם נשמרים בדוחות.

בכל הקשר דפדפן מותקנים חסמי רשת לפני טעינת העמוד: GET/HEAD בלבד יכולים להמשיך, כתיבות נענות בזיכרון או נחסמות, WebSocket ו־Service Workers חסומים. בדיקת guard יזומה עברה. בהרצה הייעודית הסופית היו 20 ניסיונות POST מדומים, חסימת כתיבה יזומה אחת של כלי הבדיקה ו־**אפס כתיבות שהועברו לרשת**. אין pageerror. סוויטת העשן הוסיפה שתי שליחות מדומות; אין פנייה אמיתית או שינוי ב־Formspree.

ערוץ המייל נבדק על ידי הרכבת URI מדומה ומניעת פעולת הניווט לאחר handler היישום. לא נפתחה אפליקציית מייל ולא נשלח מייל. בתצורה המקורית ה־fallback זמין גם כשהשליחה ל־Formspree חסומה; דגלי האישורים מגינים על מסלול Formspree.

ללא JavaScript נשארת הודעה עברית, השדות וכפתור השליחה מוסתרים, action מקומי וקישור המייל זמין. האנגלית דורשת JavaScript; לא נטען שהיא נבדקה במצב כבוי.
