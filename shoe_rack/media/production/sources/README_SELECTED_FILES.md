2. `photos/02_parts_layout.jpg`

4. `photos/04_assembled_angled.jpg`

5. `photos/05_front_view.jpg`

## Recommended editing direction
- Keep authenticity; do not over-stylize.
- Straighten perspective when needed.
- Crop distractions and improve framing.
- Correct exposure / white balance / contrast mildly.
- Keep the wood tone natural.
- Remove only minor background distractions if it can be done cleanly.
- Export optimized WebP/JPG versions for desktop and mobile.
