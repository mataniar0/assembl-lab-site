# Megillat Esther Box

Laser-cut wooden box for a Megillat Esther scroll.

## Current design
- Current approved design package: **V8.2.2**
- Exact internal clear space: **310 × 65 × 65 mm**
- Main structure: **6 mm plywood**
- Curved lid skin: **4 mm plywood**
- Curved lid uses a corrected living-hinge layout with 12 mm solid end margins and a centered 14 mm rib band
- Hinge concept: **wooden BODY_RING + wooden PIN_DISC + LOCK_CAP**
- Reinforced LID_END hinge neck
- BODY_RING mounting foot strengthened; verified actual END glue overlap: **192 mm²**
- LID_CENTER_RIB uses a positive **5+5 mm half-lap** lock into both longitudinal lid beams
- Full V8.2.2 audit: **56/56 PASS**

Versioned cutting files are stored under:
- `v8_1/` — previous 290 × 80 × 80 mm design
- `v8_2_2/` — current 310 × 65 × 65 mm audited design

> CAD geometry is nominal. No machine-specific kerf compensation is applied. Run the ring/pin calibration coupon on the actual plywood before production.
