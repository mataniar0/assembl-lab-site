# Megillat Esther Box

Laser-cut wooden box for a Megillat Esther scroll.

## Current design
- Current approved design package: **V8.1**
- Internal clear space: **290 × 80 × 80 mm**
- Main structure: **6 mm plywood**
- Curved lid skin: **4 mm plywood**
- Curved lid uses living-hinge cuts
- Hinge concept: **wooden ring + wooden pin + locking cap**
- Reinforced lid-end hinge neck

Versioned cutting files are stored under:
- `v8_1/`

> CAD geometry is nominal. Apply machine-specific kerf compensation only after testing the ring/pin fit coupon on the actual plywood.
