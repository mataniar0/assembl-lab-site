# ASSEMBL LAB — MVP-07: ניסוי הדמיית חדר סינתטי (שלב הכנה)

**סטטוס:** קוד POC ומבחנים הוכנו; לא הופעל AI אמיתי, אין חיוב ואין פריסה.
**תאריך:** 2026-11-14
**תלות:** PR #56 (Backend mock), PR #57 (Supabase development baseline). ענף הפיתוח הזה מסתמך על PR #57.

## מה ממומש

1. מנוע מחולל עשרה **חדרים סינתטיים** בפורמט PNG (384×384), ללא תמונות לקוחות.
2. מתאם `gemini-image-request.mjs` לבניית בקשות עריכת תמונה לפי Gemini Interactions API, המתאים ל־`gemini-nano-banana-2.1` ול־`gemini-3.1-flash-lite-image`.
3. מתאם ה־POC אינו מכיל פונקציית HTTP, אינו שולח בקשה לאינטרנט ודוחה ניסיון להשתמש בתמונה אמיתית.
4. תקציר DRY RUN אינו מכיל base64 של תמונות, פרומפט, הערות המשתמש או מפתחות; מציג SHA-256 וגודל תמונה בלבד.
5. מודול `evaluation.mjs` דורש ראיית תמונת פלט + הערכה אנושית בשישה מדדים (0–5 לכל אחד). **ללא תמונת פלט אמיתית, כל ניסוי נחשב UNASSESSED**.
6. CI ב־`.github/workflows/app-image-poc.yml` מייצר Artifact עם עשרה PNG וקובץ manifest. אינו מפעיל שירות בתשלום.

## מודלי השוואה ומחירים
- `gemini-nano-banana-2.1`: מוצע כמנוע מועדף לבדיקת עריכות מתמשכות; פלט 1K כ־$0.0336, לפני עלויות קלט/אחסון/מיסוי.
- `gemini-3.1-flash-lite-image`: חלופה חסכונית במהירות; פלט 1K כ־$0.0336, לפני עלויות נוספות.
- **לא** בוצעו מדידות איכות, זמן יצירה או חיוב; ההשוואה כאן מבוססת על מסמכי הספק בלבד.
- תוקף מחירים: אומת מול מסמכי הספק ב־2026-11-14, נתון לשינוי.

## חסמים לניסוי אמיתי
- חיבור Supabase טרם הושלם.
- JWT/Auth, Storage פרטי, מחיקה, הסכמה והגבלת עלות צריכים לעבור בדיקות בפועל — לא רק בדיקות קוד.
- נדרש חשבון Gemini עם גישה מתאימה ומגבלת תקציב מאושרת; אין לשמור API key במאגר או ב־PWA.
- הפעלת API בתשלום וריצות אמת מחייבות הרשאת בעל הפרויקט, ואישור מדיניות הפרטיות.
- אסור להסיק מידות או חוזק הנדסי מהדמיית AI.
