**Issue:** https://github.com/mataniar0/assembl-lab-site/issues/69

## רכיבים
- `synthetic-edit-plan.mjs`: מאמת מזהה תרחיש, SHA-256 של תמונת PNG שמורה, מזהה בקשה ייחודי ומאפייני שידה מותרים. מחזיר תקציר בלבד, ללא base64 של התמונה וללא טקסט חופשי.
- `evaluation.mjs`: רשימת שישה קריטריונים להערכה אנושית. אין תמונת פלט מאומתת → UNASSESSED. גם ציון טוב אינו אישור תכנון או ייצור.
- `run-dry-run.mjs`: מפיק תקציר ניסיון דטרמיניסטי מתוך חמש תמונות בדיקה מאומתות; אינו שולח נתונים לשום ספק.
- `dry-run.test.mjs`: בדיקות תקפות, חסימה, ולידציית קבצים, אפס קריאות רשת ואפס עלות.

## אבטחה — חסום כברירת מחדל
- קלט מותרים בלבד: אחת מחמש התמונות SC-01/02/04/07/10 + hash מניפסט + מאפייני שידה בסיסיים + מזהה אידמפוטנטי.
- אסור: תמונה אמיתית, קובץ מצלמה, כתובת URL חיצונית, הערות משתמש, מזהים אישיים, סיסמאות, JWT, מפתחות API, הצעות ספק או סכום חיוב.
- הפונקציה `callLiveProvider()` דוחה כל בקשה ללא חריג. אין SDK, אין HTTP client, אין קוד טעינת מפתחות.
- `approved_budget_usd=null` ו־`price_estimate_usd=null` — לא בוצעה הערכת עלות בת־תוקף ואין אישור חיוב.
- `network_calls=0`, `paid_calls=0`, `image_output_generated=false`, `outcome=UNASSESSED` בכל תקציר.

## נוהל לפני מעבר ל־MVP-10-B
1. לוודא בנפרד את הגדרות Supabase Auth, ההרשאות עם שני JWT אמיתיים, Storage פרטי, השהיה/מחיקה ו־Consent.
2. לבדוק מחדש את ממשק ספק ה־AI, שמות המודלים הנוכחיים, תמחור מעודכן ותנאי שמירת מידע. מתאם MVP-07 הישן אינו נחשב לנתון עדכני.
3. לבחור תרחיש סינתטי יחיד, לאשר בכתב מקסימום בקשות וסכום כולל; להגדיר חסם שרת בר־אכיפה לפני הקריאה הראשונה.
4. לבצע ביקורת אבטחה עצמאית ותיעוד תוצאות. פרסום/מיזוג PR דורשים אישור בעל הפרויקט, בנפרד מאישור חיוב.
5. רק אז לבנות מתאם שרת חדש. אל תחבר מפתח API ל־PWA/JavaScript ציבורי.
